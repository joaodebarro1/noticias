#
#  Cada assunto começa com o nome entre colchetes:  [NOME DO ASSUNTO]
#    buscar:    o que pesquisar no Google News, separado por ;
#               aceita OR e "aspas":  Raízen OR RAIZ4;  "Vibra Energia" OR VBBR3
#               o OR junta só as palavras vizinhas:
#                 ANP multa OR fiscalização  =  ANP + (multa ou fiscalização)
#               cada busca traz até 100 notícias do último dia
#    palavras:  palavra=peso, separadas por vírgula
#
#  PESOS — decidem se a notícia é enviada:
#    4  basta sozinha           (nomes sem ambiguidade: Petrobras, RAIZ4, ANP)
#    3  palavra principal        precisa de mais 1 palavra qualquer da lista
#    2  contexto                 nunca dispara sozinha, só reforça
#    1  contexto fraco           idem, para palavras genéricas (preço, alta)
#
#  Nota = soma dos pesos de todas as palavras encontradas (+ URGENTES)
#    🔴 nota 8 ou mais    🟡 nota 5 a 7    ⚪ nota até 4
#    Só 🔴 e 🟡 são enviadas (Telegram: 🔴 e 🟡; WhatsApp: só 🔴). ⚪ é ignorada.
#
#  Como as palavras são encontradas:
#    - maiúsculas e acentos não importam (raizen = Raízen)
#    - a palavra precisa aparecer inteira (vibra NÃO pega "vibração")
#    - * aceita variações: combustíve* -> combustível, combustíveis
#    - dá para usar expressões: bandeira branca=2
#
#  Seções especiais:
#    [URGENTES]  palavras que somam pontos em qualquer assunto
#    [IGNORAR]   palavras que descartam a notícia (ex.: notícias policiais em postos)
#    [FONTES]    de onde vêm as notícias, um por linha:
#                  agregador: google news   -> roda as buscas de cada assunto nele
#                  agregador: bing news        (idem)
#                  https://...              -> RSS de um site, lido inteiro
#                  site:dominio.com termos  -> busca extra no Google News
#                  ... (en)                 -> busca na edição em inglês (Reuters, Argus...)
#
#  Ao mudar este arquivo, a próxima execução só memoriza as notícias
#  existentes (sem enviar), para não chegar uma enxurrada de alertas.
# =====================================================================
